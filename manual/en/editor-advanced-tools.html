Editor Advanced Tools

This page documents the advanced modeling and control features recently added to the editor: the selection modes, modeling utilities, geometry clipboard, and command terminal overlay.

Selection modes and overlays

The Geometry sidebar now exposes an explicit selection mode switcher (object, vertex, edge, face) and a live selection info label. The viewport overlay mirrors that state so you can see the current mode and any picked element indices.

  • Sidebar controls: the selector and info rows live alongside geometry metadata, reusing the same UI flow as the rest of the Geometry panel.
  • Viewport overlay: the info box shows the active mode and the selected vertex, edge, or face index whenever geometry picking is active.

Modeling utilities (Bounding volumes, insets, extrudes, and merge vertices)

The Geometry modifiers panel adds ready-to-run modeling helpers. Each button checks for an AxisFrame before mutating geometry and follows the same in-place signal dispatch as the existing normals/tangents tools.

  • Compute bounding box: runs BufferGeometry.computeBoundingBox(), following the usage shown in examples/webgl_geometry_text_shapes.html.
  • Compute bounding sphere: runs BufferGeometry.computeBoundingSphere() as in examples/webgl_buffergeometry_drawrange.html.
  • Inset shape: rebuilds ShapeGeometry instances from their stored shapes array (same pattern as examples/webgl_geometry_shapes.html) and scales them toward the center to create an inset shell.
  • Extrude shape: applies ExtrudeGeometry with the beveled settings lifted from the third extrude block in examples/webgl_geometry_extrude_shapes.html (depth 20, bevel enabled, thickness 2, size 4, 1 step/segment).
  • Merge vertices: reuses BufferGeometryUtils.mergeVertices() the same way it appears in examples/webgl_custom_attributes_points3.html to weld duplicate vertices.
  • Spiral array: clones the selected object into a sin/cos spiral that mirrors the polar offsets shown in examples/webgl_shadowmesh.html (the rotating torus/cube placements around lines 195–207), with controls for count, radius, height, angular step, and whether to rotate each clone outward. The helper still enforces ensureAxisFrame() before running.

Geometry clipboard (copy / paste)

The Geometry sidebar exposes Copy and Paste buttons that mirror the editor’s serialization pipeline. Copy stores geometry.toJSON() on an editor clipboard, and Paste reconstructs it through ObjectLoader.parseGeometries() before applying it with SetGeometryCommand.

  • The Paste button only enables when clipboard data exists and applies the reconstructed geometry back to the selected object.
  • The command pipeline keeps undo/redo history consistent with other geometry edits.

Command terminal overlay

An AutoCAD-like command terminal sits next to the viewport info overlay. It uses the same floating panel layout pattern and hooks into editor commands with AxisFrame preconditions before touching selection or geometry.

  • Overlay behavior: toggle visibility, type commands, and browse history with the arrow keys. Output lines are preserved up to 50 entries.
  • Supported commands: help, select (by name or UUID), delete/del, focus, mode (object/vertex/edge/face), move (x y z), copygeom, and pastegeom.
  • Preconditions: operations like select, delete, move, copy, and paste call ensureAxisFrame() before executing commands, matching the broader AxisFrame requirement.

These tools are designed to stay aligned with existing editor patterns: they reuse Sidebar row layouts, the viewport overlay pattern, the command/undo system, and BufferGeometryUtils helpers pulled directly from documented three.js examples.
